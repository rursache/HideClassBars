# HideClassBars
A World of Warcraft addon that hides class-specific stance bars (stance, shapeshift, stealth, etc.) and optionally other UI clutter

It currently supports World of Warcraft 11.1.5 and hiding the following stance bars:
- Warrior Stance Bar
- Priest Shadow Form Bar
- Rogue Stealth Bar
- Druid Shapeshift Bar
- Paladin Aura Bar

Extra features
- Hides the vehicle seat frame

Available on [Curseforge](https://legacy.curseforge.com/wow/addons/hideclassbars)
